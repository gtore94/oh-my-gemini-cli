# Skill: omc_toolkit

## Purpose
A collection of utility skills from oh-my-claudecode.

## Skills Included

### /ask <provider> <query>
- **Action**: Consult external models (Claude, Codex, Gemini) using local CLIs or MCP.

### /deepinit
- **Action**: Generate or update the `AGENTS.md` and project orchestration index.

### /external-context
- **Action**: Research external documentation, GitHub repos, or SDKs in parallel.

### /skillify (or /learner)
- **Action**: Extract reusable patterns, debugging knowledge, or architectural decisions into portable skill files.

### /release
- **Action**: Automate the release workflow (version bump, changelog, tagging).

### /verify
- **Action**: Strictly verify a change with fresh evidence before claiming completion.

### /sciomc
- **Action**: Orchestrate parallel scientist agents for data analysis or research.

### /visual-verdict
- **Action**: Perform visual regression or UI consistency checks.

### /wiki
- **Action**: Manage project documentation and internal wikis.

### /remember
- **Action**: Persist critical information or directives into the project memory.
